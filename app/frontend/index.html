本機 AI Agent 0.0.1

    
企業 Windows 本機工具。專案檔留在這台電腦；發佈 n8n 與 OpenRPA 整合包需要你批准，而且不會自動啟用或立刻執行桌面。

    
安裝只下載一個壓縮檔，解壓後雙擊 一鍵安裝.bat。介面在 127.0.0.1:8765。127.0.0.1:8771 是本產品自製 Broker，不是 OpenRPA 官方 REST。

    
OpenRPA 1.4.57.13 為 MPL-2.0。n8n 壓縮檔含上游 .ee. 檔，再散布受其授權限制。

    

      
    

  

  
    

      
說明

      
    

    
解壓發行包後雙擊 一鍵安裝.bat。公司電腦請用 cmd，不要用 PowerShell、pip 或 npm 安裝。

    
Agent 只能改目前專案。一般模式可修改與執行；計畫模式只規劃；唯讀模式只回答。publish 與 OpenRPA 整合部署需要批准，且不會自動啟用或執行桌面流程。

    
本機搜尋走 SearXNG MCP。依賴說明在匯入 filesystem/system/knowledge/dependencies.sqlite 後可供 AI 檢索。

MCP 在本機運作；搜尋文字會送至下方 SearXNG 上游。只取搜尋摘要，不另抓取網頁。
